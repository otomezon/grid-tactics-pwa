# Grid Tactics PWA

スマートフォンのブラウザで遊べる、オフライン対応を目指したターン制タクティカルSRPGのプロジェクトです。

## 現在の開発状況

アプリ起動時はタイトル画面を表示し、「つづきから」「はじめから」を選択します。新規開始は出撃配置の確定まで既存の自動セーブを保持します。セーブJSONの読み込み／書き出し、ローカル3世代バックアップの作成／復元もタイトル画面から利用できます。第3章の試作マップを追加し、全3章の遷移はデータ駆動でつながります。3章とも正式シナリオ・最終バランスではありません。

- PR #1〜#99は `main` にマージ済みです。最新はPR #99（merge commit `d978ee42a13426ce50f13e97d80cf52d9cbf20bf`、main CI run #1182成功）。PR #99でキャンペーン累計戦績のsaveVersion 4保存・章間引き継ぎを追加しました。
- 出撃準備の候補詳細から、出撃予定／控え予定の味方が所持する使用可能な武器を装備・解除できます。変更は配置確定時に保存され、セーブ形式 `saveVersion: 4` を使用します。
- 出撃準備では、出撃予定／控え予定から2人を選んで能力値・成長率・装備適性を横並び比較できます。表示専用で、編成・装備・セーブを変更しません。
- 出撃準備と戦闘中の味方詳細で、8能力の成長率と次のレベルまでのEXP進捗を確認できます。表示は読み取り専用で、成長判定や乱数状態には触れません。
- ステージ結果では、現ステージの味方攻撃貢献と、saveVersion 4に保存するキャンペーン累計戦績を分けて表示します。味方開始攻撃の命中／ミス／必殺・実与ダメージ・撃破・EXP・レベルアップ／能力上昇を味方IDごとに累計し、リロード／章移行後も保持します。敵の反撃は除外します。
- PR #84で、開発専用の実セーブsnapshotベンチに7基本職×3profileの21ケース候補マトリクス、一括のペア戦闘評価、CSV出力を追加しました。各ケースの候補・敵・条件は利用者が確認してから実行します。
- PR #86では、既存の敵軍フェイズ解決を使うpaired 1-phase昇格比較を追加しました。controlは昇格せず行動を見送り、promotionは昇格で行動を消費します。これは複数ターンや次の自軍行動を再現する実プレイではありません。「実プレイ由来」の区分は利用者申告で真正性を自動検証しません。
- CP-04／05の正式な能力ボーナス・クラス別上限、および最初の昇格アイテムの章／イベント・受取人・数量は未決定です。クラス定義は `src/content/class-definitions.ts` に14職の型付きレジストリとして集約し、現在の仮上限・仮ボーナスは非承認のまま保持します。移動力・移動種別・武器適性はCP-09／10の正式データが未決定のため既存ユニット値を維持します。試作値や合成fixtureを正式バランスとして扱いません。
- セーブ形式は `saveVersion: 4` を使用しています。v1／v2／v3のセーブから自動移行します。昇格ベンチ（`/?promotion-snapshots=1`）のsnapshot・比較結果はメモリ上のみで、IndexedDB／GameState／自動保存／ネットワーク送信を行いません。
- 章遷移はデータ駆動で、第2章は引き継ぎ動作確認用の試作マップです。正式な章報酬の内容・数量は未設定です。
- 移動プレビューは既存の地形コスト・通行不可地形・占有マス・移動力を使った表示専用機能で、移動ルールやバランス値を変更しません。
- 操作ガイドは出撃準備・移動・攻撃予測・アイテム／行動・地形・ターン／保存を順に説明する任意表示のヘルプです。ガイドを開閉・閲覧してもゲーム状態やセーブは変わりません。
- マップ・ユニット・武器の能力値は操作確認用の仮データです。敵AIはクラス側の役割タグによる遠距離攻撃役の暫定優先、移動先の理由、攻撃対象候補と移動先候補ごとの評価内訳を予測／戦闘履歴に表示します。既存のスコア式・候補順・行動結果は変更せず、全スコアは正式なバランス値ではありません。AIスコア・役割加点・距離方式は正式なバランス値ではありません。
- クラスチェンジの能力ボーナス／クラス上限は暫定値です。章報酬は設定データが定義された場合のみ配布し、未設定の試作章にアイテムを勝手に付与しません。
- 出撃準備は [docs/deployment.md](docs/deployment.md)、実装状況は [docs/current-state.md](docs/current-state.md)、敵AIの判断と未決定事項は [docs/enemy-ai.md](docs/enemy-ai.md) を参照してください。

## 技術スタック

- Node.js 26（許容: Node 22.12+、24+、26+）
- npm
- React 19.3.1 / React DOM 19.3.1
- TypeScript 7.0.2
- Vite 8.3.6
- vite-plugin-pwa 2.0.0
- Vitest 5.0.0
- Playwright Test 1.65.0（Chromium E2E）
- IndexedDB（ブラウザ内の自動保存、JSON export/import、最大3世代の手動ローカルバックアップ／確認付き復元、saveVersion 4／v1・v2セーブ移行）

## セットアップ

```bash
npm install
npm run dev
```

主な確認コマンド:

```bash
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

初回の `npm install` で `package-lock.json` を生成し、依存関係の再現性を確保するため別途コミットしてください。詳細は [docs/development.md](docs/development.md) を参照。
