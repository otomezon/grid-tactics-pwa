# Grid Tactics PWA

スマートフォンのブラウザで遊べる、オフライン対応を目指したターン制タクティカルSRPGのプロジェクトです。

## 現在の開発状況

アプリ起動時はタイトル画面を表示し、「つづきから」「はじめから」を選択します。新規開始は出撃配置の確定まで既存の自動セーブを保持します。セーブJSONの読み込み／書き出し、ローカル3世代バックアップの作成／復元もタイトル画面から利用できます。第3章の試作マップを追加し、全3章の遷移はデータ駆動でつながります。3章とも正式シナリオ・最終バランスではありません。 現在の試作3章では `unit_001` を主人公の保護対象に設定し、第1章は `enemy_005`（敵将）の撃破を勝利条件にしています。これは初期キャンペーンの動作確認用の仮設定で、正式な人物設定・物語・ステージ構成ではありません。

- PR #1〜#109は `main` にマージ済みです。PR #102ではプレイヤーcommand境界とマップイベント基盤、PR #103では未確認イベントの再表示・確認状態保存（saveVersion 6）、PR #104ではイベントダイアログに対応したE2Eセットアップ、PR #105では現章のイベント履歴、PR #106ではターン終了レビューの敵攻撃対象／味方全員の予測HP表示、PR #107では敵攻撃のstrike別予測詳細を追加しました。 PR #108では敵行動の開始位置・移動先・攻撃対象をマップ上で一時確認できるようにしました。 PR #109では3章の主人公敗北条件と第1章の敵将撃破による勝利条件を接続しました。PR #110では勝利／敗北リザルトからセーブを保持したままタイトルへ戻り、同じ結果を再開できるようにしました。
- 出撃準備の候補詳細から、出撃予定／控え予定の味方が所持する使用可能な武器を装備・解除できます。変更は配置確定時に保存され、セーブ形式 `saveVersion: 6` を使用します。
- 出撃準備では、出撃予定／控え予定から2人を選んで能力値・成長率・装備適性を横並び比較できます。表示専用で、編成・装備・セーブを変更しません。
- 出撃準備と戦闘中の味方詳細で、8能力の成長率と次のレベルまでのEXP進捗を確認できます。表示は読み取り専用で、成長判定や乱数状態には触れません。
- 勝利／敗北リザルトから「タイトルへ戻る」を選べます。移動は画面遷移のみで、自動セーブを変更・削除せず、タイトルの「つづきから」で同じリザルトへ戻れます。
- ステージ結果では、現ステージの味方攻撃貢献と、saveVersion 6に保存するキャンペーン累計戦績を分けて表示します。味方開始攻撃の命中／ミス／必殺・実与ダメージ・撃破・EXP・レベルアップ／能力上昇を味方IDごとに累計し、リロード／章移行後も保持します。敵の反撃は除外します。
- PR #84で、開発専用の実セーブsnapshotベンチに7基本職×3profileの21ケース候補マトリクス、一括のペア戦闘評価、CSV出力を追加しました。各ケースの候補・敵・条件は利用者が確認してから実行します。
- PR #86では、既存の敵軍フェイズ解決を使うpaired 1-phase昇格比較を追加しました。controlは昇格せず行動を見送り、promotionは昇格で行動を消費します。これは複数ターンや次の自軍行動を再現する実プレイではありません。「実プレイ由来」の区分は利用者申告で真正性を自動検証しません。
- CP-04／05の正式な能力ボーナス・クラス別上限、および最初の昇格アイテムの章／イベント・受取人・数量は未決定です。クラス定義は `src/content/class-definitions.ts` に14職の型付きレジストリとして集約し、現在の仮上限・仮ボーナスは非承認のまま保持します。移動力・移動種別・武器適性はCP-09／10の正式データが未決定のため既存ユニット値を維持します。試作値や合成fixtureを正式バランスとして扱いません。
- マップイベントはマップ定義のデータとして記述し、ステージ開始・指定ターン／フェイズ・ユニット撃破・ボス撃破・勝利／敗北を一度ずつ発火できます。現段階のアクションはメッセージ表示のみで、発火済みIDをsaveVersion 6へ保存します。
- ターン終了前レビューと敵軍フェイズ予測では、敵の攻撃対象と味方全員の予測HP・被ダメージ・撃破見込みに加えて、選ばれた攻撃の初撃／反撃／追撃ごとの命中率・通常／必殺ダメージ・武器相性を確認できます。実行後の一時戦闘履歴でも同じ攻撃予測を参照できます。各敵行動の「マップで確認」から開始位置・実際に選ばれた移動先・攻撃対象をマップ上で一時強調表示できます。これらの閲覧・選択はゲーム状態や自動保存を変更しません。
- イベントメッセージは確認ダイアログで表示し、確認状態もsaveVersion 6へ保存します。未確認のまま再読み込みしても再表示され、確認済みなら再表示しません。敵軍フェイズ開始イベントは確認されるまで敵AIを進めません。v5セーブは発火済みIDを確認済みとしてv6へ移行し、旧イベントを意図せず再表示しません。
- 発火済みのメッセージは「イベント履歴」から現章内で発生順に読み返せます。確認済みメッセージも対象で、マップ定義と既存の発火済みIDから再構成する読み取り専用UIです。新しいセーブ項目や発生時刻は追加しません。
- セーブ形式は `saveVersion: 6` を使用しています。v1〜v5のセーブから自動移行します。昇格ベンチ（`/?promotion-snapshots=1`）のsnapshot・比較結果はメモリ上のみで、IndexedDB／GameState／自動保存／ネットワーク送信を行いません。
- 章遷移はデータ駆動で、第2章は引き継ぎ動作確認用の試作マップです。正式な章報酬の内容・数量は未設定です。
- 移動プレビューは既存の地形コスト・通行不可地形・占有マス・移動力を使った表示専用機能で、移動ルールやバランス値を変更しません。
- 操作ガイドは出撃準備・移動・攻撃予測・アイテム／行動・地形・ターン／保存を順に説明する任意表示のヘルプです。ガイドを開閉・閲覧してもゲーム状態やセーブは変わりません。
- マップ・ユニット・武器の能力値は操作確認用の仮データです。敵AIはクラス側の役割タグによる遠距離攻撃役の暫定優先、移動先の理由、攻撃対象候補と移動先候補ごとの評価内訳を予測／戦闘履歴に表示します。既存のスコア式・候補順・行動結果は変更せず、全スコアは正式なバランス値ではありません。AIスコア・役割加点・距離方式は正式なバランス値ではありません。
- クラスチェンジの能力ボーナス／クラス上限は暫定値です。章報酬は設定データが定義された場合のみ配布し、未設定の試作章にアイテムを勝手に付与しません。
- 出撃準備は [docs/deployment.md](docs/deployment.md)、実装状況は [docs/current-state.md](docs/current-state.md)、敵AIの判断と未決定事項は [docs/enemy-ai.md](docs/enemy-ai.md) を参照してください。

## 技術スタック

- Node.js 26（許容: Node 22.12+、24+、26+）
- npm
- React 19.3.1 / React DOM 19.3.1
- TypeScript 7.0.2
- Vite 8.3.6
- vite-plugin-pwa 2.0.0
- Vitest 5.0.0
- Playwright Test 1.65.0（Chromium E2E）
- IndexedDB（ブラウザ内の自動保存、JSON export/import、最大3世代の手動ローカルバックアップ／確認付き復元、saveVersion 6／v1〜v5セーブ移行）

## セットアップ

```bash
npm install
npm run dev
```

主な確認コマンド:

```bash
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

初回の `npm install` で `package-lock.json` を生成し、依存関係の再現性を確保するため別途コミットしてください。詳細は [docs/development.md](docs/development.md) を参照。
