## 4. 採択済みの非数値ルール（2026-11-10）

| ID | 決定対象 | 採択済み方針 | 決定 |
|---|---|---|---|
| CP-07 | 昇格時EXP | 昇格後も0〜99のEXP端数を保持する | 採択済み |
| CP-08 | HPボーナス | 最大HPのみ増加し、現在HPは維持する | 採択済み |
| CP-09 | 移動性能 | 正式な昇格先の移動データが承認されるまでは、昇格前の `move`／`movementType` を維持する | 採択済み |
| CP-10 | 武器適性 | 正式な昇格先の武器データが承認されるまでは、基本職の `usableWeaponTypes` を維持する | 採択済み |
| CP-11 | 使用不可になる装備 | 将来、承認済みクラスデータで装備武器が使用不可になった場合は自動解除し、武器は所持品に残す。CP-10により現時点では発生しない | 採択済み |
| CP-12 | 行動消費 | 自軍フェイズ中かつ未移動・未行動のユニットだけ昇格可とし、昇格をそのユニットの行動として消費する | 採択済み・実装済み |
| CP-13 | アイテム配布 | 明示された章報酬／イベントでのみ配布し、既存セーブへ遡及付与しない。具体的な章・受取人・数量は別途未決定 | 採択済み |
| CP-14 | 所持品満杯 | 所持品枠が足りない報酬を無言で破棄せず、明示的に受け取りを拒否／保留する | 採択済み |
| CP-16 | 初期版の拡張範囲 | 各基本職から一度だけ昇格。分岐・再昇格・降格は初期版に含めない | 採択済み |

採択内容の根拠は [Issue #26の2026-11-10付コメント](https://github.com/otomezon/grid-tactics-pwa/issues/26#issuecomment-)。この表の採択済み表示は非数値方針に限る。**CP-04／CP-05の能力上限・昇格ボーナス数値、CP-06の既存能力が昇格先上限を超えている場合の扱い、クラス別の正式な移動／武器データ、CP-01〜CP-03、CP-15、および最初の証の配布元・受取人・数量は未決定のまま**とする。
