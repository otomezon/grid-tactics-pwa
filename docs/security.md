## 3. ローカルセーブデータ

- IndexedDBに保存する値は信頼できる入力とみなさず、ロード時にスキーマとゲーム上の不変条件を検証する。
- セーブデータをブラウザ内に保存することは暗号化や改ざん防止を意味しない。機密情報や認証情報を保存しない。
- セーブバージョン、マイグレーション、バックアップ、破損時の通知・復旧方針を明確にする。
- ストレージ消去・容量不足・プライベートブラウジング等により保存が失われる可能性をUIで適切に説明する。

## 4. Webアプリ・PWA

実装時に確認・対策する項目:

- HTTPS配信と安全なホスティング設定。
- ユーザー入力・コンテンツデータの検証。
- React等の通常のエスケープを迂回する危険なHTML挿入を避ける。

- Service Workerのスコープ、キャッシュ対象、更新・失効手順をレビューし、古いコードと新しいデータの不整合を防ぐ。
